# Как опубликовать ShopGuard на GitHub

Эта инструкция рассчитана на публикацию проекта через сайт GitHub, без командной строки.

## 1. Создать репозиторий

1. Войти в свой аккаунт на [GitHub](https://github.com/).
2. Нажать **New repository**.
3. Назвать репозиторий `ShopGuard-QA-Automation`.
4. Выбрать **Public**, если проект должен быть виден всем.
5. Не добавлять автоматически README, `.gitignore` или License: эти файлы уже есть в проекте.
6. Нажать **Create repository**.

## 2. Загрузить файлы

1. Распаковать архив ShopGuard на компьютере.
2. Открыть созданный репозиторий на GitHub.
3. Нажать **Add file → Upload files**.
4. Перетащить содержимое папки `ShopGuard-QA-Automation` в окно загрузки. Загружать нужно сами папки и файлы проекта, а не ZIP-архив целиком.
5. Внизу страницы в поле сообщения написать `Add ShopGuard 1.9.4 final project`.
6. Нажать **Commit changes**.

## 3. Что должно быть в репозитории

В корне должны находиться `README.md`, `CHANGELOG.md`, `LICENSE`, `requirements.txt`, папки `dashboard`, `shopguard`, `pages`, `tests`, `docs`, `scripts`, `postman` и `.github`. GitHub Actions автоматически запустит локальные тесты после загрузки.

## 4. Что не загружать

Не добавляйте личные настройки и результаты локальной работы: `.env`, `.venv`, `reports`, `__pycache__`, `.pytest_cache`. Они уже перечислены в `.gitignore`. Не добавляйте пароли, токены или личные данные.

## 5. После публикации

Откройте вкладку **Actions** и дождитесь завершения проверки **ShopGuard QA**. Для обычной публикации достаточно автоматических offline/unit checks. Дополнительные live-проверки запускаются отдельно и обращаются к публичному демонстрационному сайту.

Готово: в репозитории будет исходный код, инструкция по запуску, тестовая документация и автоматическая проверка GitHub Actions.
