Check a website

Enter a public website address. ShopGuard will open it in a browser and check its main parts.

Website check

ShopGuard opens the page in a temporary browser and performs a short, read-only check. It does not sign in, click buttons, submit forms, change the cart or place orders. PASS = check observed as OK; WARN = possible issue or environment signal to review; FAIL = a stronger problem signal; INFO = not tested, a recommendation or a scan limitation. A result is not proof that the whole site is defect-free.

Enter a public website address. Local and private addresses are blocked.

Data management

Protect your saved projects, run history and local test evidence.

Local backups · no cloud

Backup and restore

ZIP backups include project profiles, run history and referenced logs, JUnit reports, JSON evidence and screenshots. Referenced evidence is capped at 15 MB per backup; if older/large files exceed that cap, ShopGuard reports how many were omitted. Credentials, .env and the Python environment are never included.

Automatic backup is created before project edits, deletions and restore operations. The five newest automatic backups are retained.
